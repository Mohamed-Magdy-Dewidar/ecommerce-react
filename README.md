# 🛒 E-commerce React App

This is a full-featured e-commerce frontend application built with **React.js**, showcasing modern authentication, product browsing, and user interaction.

## 🔐 Features
- User signup/login with JWT token authentication
- Protected store access after login
- Filter products by category
- Add items to cart and wishlist
- Checkout simulation
- Form validation with Formik & Yup
- Notifications using react-hot-toast

## 🛠️ Tech Stack
- React.js
- Axios
- JWT
- Formik + Yup
- react-hot-toast
