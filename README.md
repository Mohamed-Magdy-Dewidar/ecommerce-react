# 🛒 E-commerce React App

This is a full-featured e-commerce frontend application built with **React.js**, showcasing modern authentication, product browsing, and user interaction.

## 🔐 Features

- User signup and login with **JWT authentication**
- Protected store access after login
- Add products to **Cart** or **Wishlist**
- Filter and view products by category
- Form validation with **Formik** and **Yup**
- Notifications using **react-hot-toast**
- Token-based API requests using **Axios**

## 🛠️ Tech Stack

- React.js
- Axios
- JWT (JSON Web Token)
- Formik + Yup
- react-hot-toast

## 📁 Setup Instructions

1. Clone this repository:
```bash
git clone https://github.com/Mohamed-Magdy-Dewidar/ecommerce-react.git
```

2. Navigate into the project directory:
```bash
cd ecommerce-react
```

3. Install dependencies:
```bash
npm install
```

4. Start the development server:
```bash
npm run dev or npm start
```
